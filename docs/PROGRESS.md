Cause: `CudaLibraryProbe` loaded cuDNN 9.28 from `nvidia-cudnn-cu12` for CTranslate2, then torch's bundled cuDNN 9.10.2 (same file names) bound to it. After the fix: `--speakers auto` exit 0, `Transcription running on: cuda (float16)`, `Diarization running on: cuda`, 590 turns, 5 speakers, 551 lines, 0 bidi controls; 122.8 s first run including the pyannote download, 118.5 s cached. Plain GPU re-run after the fix: 96.8 s, 458 lines (before: 97.7 s, 458), so no regression. CPU, forced with `CUDA_VISIBLE_DEVICES=-1`: `cpu (int8, 16 threads)`, `ivrit-ai/whisper-large-v3-turbo-ct2` (pre-fetched so the time excludes the download), 270.8 s, 437 lines, 6.2× realtime. **2026-11-25 — Windows GPU transcription verified on real hardware; transcripts no longer carry invisible bidi control characters; two tests fixed for Windows (offline code + tests + docs; one-time model download, no paid API calls). ✅ DONE**
First real run of the Windows install and the NVIDIA GPU path. On Windows 11 Pro (10.0.26200), Python 3.13.7, RTX 4090: `py -3.13 install.py --gpu` installed faster-whisper 1.2.1, ctranslate2 4.9.1, nvidia-cublas-cu12 12.9.2.10 and nvidia-cudnn-cu12 9.28.1.4; `transcribe.py --capabilities` printed `{"diarization": false, "engine": "faster-whisper", ...}`. That run surfaced two things. (1) 159 of 458 lines held U+202B (RLE), sometimes mid-line (`קבוצה ‫שאנחנו`), coming from the model's output, not from this project's code; `transcript_output.clean_text()` now strips all bidi controls at render time for plain, labelled and fallback text, and drops a segment that is only controls (decision row 1). Re-run on the same file: 458 lines, 0 bidi controls. (2) The unit suite was 167 passed / 2 failed / 1 skipped on Windows; both failures were test bugs, not product bugs: `test_a_real_cp1252_stream_can_print_hebrew_afterwards` got `\r\n` from a default `TextIOWrapper` on Windows, and `test_mac_still_unescapes_drag_and_drop` simulated macOS on a Windows temp path whose backslashes got unescaped away (decision row 2). Proof after the change: `.venv/Scripts/python -m unittest discover -s tests -t .` → `Ran 178 tests ... OK (skipped=1)` (the skip is the Mac-only setup.sh test).
